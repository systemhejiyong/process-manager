# 进程查找关闭工具 — UI Spec v2

## 设计原则
- Win / Linux 同一套布局与交互，仅文案与路径格式随系统变化。
- 参考截图只提供信息架构；视觉层级、筛选分区、批量操作重新设计，不照搬青绿大顶栏。
- 危险操作只用红色；主操作青绿；中性操作为描边按钮。

## 间距
- 窗口内边距 16
- 卡片间距 12
- 控件间距 8
- 表行高 ≈ 32（单元格上下 7）
- 圆角：窗口 10 / 卡片 8 / 按钮与输入 6 / 胶囊 4

## 组件
- **分段控件**：进程名 | 端口（互斥搜索模式）
- **主按钮** accent 实心；**次按钮** 白底描边；**危钮** danger 实心
- **表格**：固定表头；选中行 `accent.soft`；端口用胶囊；空值「—」灰色
- **相关进程**：主表选中后出现；勾选汇总文案在区头右侧
- **确认对话框**：居中模态 + 半透明遮罩；列出将结束数量；取消 / 确认关闭
- **空态**：插画位（可先用简洁图标）+ 一句引导 + 示例「试试搜 node 或端口 5173」
- **无权限**：行内或 Toast 不静默；关闭失败写日志；顶栏徽章保持「标准用户」

## 平台文案差异
| Windows | Linux |
|---------|-------|
| 以管理员身份重新启动 | 提权重新启动 |
| `C:\…` 路径 | POSIX 路径 |
| 服务列可显示服务名 | 服务列多为 — |
