# 进程查找关闭工具 — UI Spec v2

## 设计原则
- Win / Linux 同一套布局与交互，仅文案与路径格式随系统变化。
- 参考截图只提供信息架构；视觉层级、筛选分区、批量操作重新设计，不照搬青绿大顶栏。
- 危险操作只用红色；主操作青绿；中性操作为描边按钮。

## 组件
- **分段控件**：进程名 | 端口（互斥搜索模式）
- **主按钮** accent 实心；**次按钮** 白底描边；**危钮** danger 实心
- **表格**：固定表头；选中行 `accent.soft`；端口用胶囊；空值「—」灰色
- **相关进程**：主表选中后出现；勾选汇总文案在区头右侧
- **确认对话框**：居中模态 + 半透明遮罩；列出将结束数量；取消 / 确认关闭
- **空态**：插画位（可先用简洁图标）+ 一句引导 + 示例「试试搜 node 或端口 5173」
- **无权限**：行内或 Toast 不静默；关闭失败写日志；顶栏徽章保持「标准用户」

## 加载与默认空态（v2 补充，2026-10-15）

### 默认打开
- **不**自动刷新/枚举全量进程；匹配结果区为引导空态（文案：先搜索再看结果）。
- 示例提示：`node` / `python` / 端口 `5173`。

### 搜索 loading
- 点击「查找」或「按端口查」后：主按钮文案改为「查找中」并带白色 spinner；刷新等次按钮禁用。
- 结果区显示居中 spinner + 一句说明（含当前关键词/端口）+ 不确定进度条（accent）。
- 请求结束后恢复按钮，再渲染表格或「无结果」空态。

### 相关进程 loading
- 选中主表一行后，相关进程区**立即**出现，先显示行内 spinner +「正在加载…」；禁止空白干等。
- 加载完成后替换为勾选表；若失败，区内红字错误，不拖垮主表。
- 建议：超过约 3s 区头副文案变为「仍在加载…」；实现侧应缓存/限范围，避免每次全扫。

交付：`v2_loading.png` / `v2_loading.html`

## 进程行右键菜单（v2 补充，2026-10-15）

主表进程行右键弹出菜单（Win/Linux 同结构）。

### 结构（上动作 / 下复制，中间分隔线）
1. **关闭此进程** — 仅结束当前行；走现有确认框与硬拦截规则。
2. **关闭此进程及相关进程** — 结束当前行 + 相关区已勾选项（若相关尚未加载，先按「父/同路径/同项目目录」默认勾选集）；同样走确认与硬拦。
3. ———
4. 复制进程名
5. 复制 PID
6. 复制完整路径
7. 复制监听端口（无端口则复制 `—` 或禁用该项，实现二选一：建议禁用）
8. 复制项目目录（无则禁用）
9. 复制命令行

### 视觉
- 白底、圆角 6、轻阴影；字号 12；行高 32；左右内边距 12。
- 悬停：背景 `#EFF6FF`（或系统选中蓝），文字保持 `text.primary`；危项「关闭…」悬停可用同一选中态，不单独标红（与参考图一致）。
- 菜单贴鼠标，勿遮挡整行关键列；超出窗口边缘时翻转。

### 交互
- 右键同时选中该行（展开/准备相关进程）。
- 复制成功可用短 Toast「已复制」1.5s，或静默；首版静默即可。
- 硬拦截进程：两项关闭仍可点，点后走拦截提示，不真正结束。

交付参考：用户截图；示意 `v2_context_menu.png`

## 一屏布局（v2 补充，2026-10-15）

窗口内容必须**一屏铺满，禁止外层（窗口/页面级）滚动条**。

### 分区与滚动
| 区域 | 行为 |
|------|------|
| 顶栏工具区 | 固定高度，不滚动 |
| 匹配结果 | 占主区弹性高度（建议 min ≈ 40% 可用高）；表体区内滚动，表头固定 |
| 相关进程 | **默认压矮**：未选主表行时收起或仅区头（≈36px）；选中后展开，高度上限约 **18%**（可视约 **2–3 行**即可），区内自滚；不以凑满 4–5 行为验收条件 |
| 操作日志 | 固定高度（建议 ≈ 100–120px）；区内自滚，新日志贴底 |

### 约束
- `html/body` 与根布局 `overflow: hidden`；仅上述三块内容区 `overflow: auto`。
- **匹配结果优先吃满**剩余高度（建议 ≥ 50% 可用高）；相关进程不得与日志把主表挤出一屏。
- 缩小窗口时优先再压相关进程 → 再压日志，**仍不出现外层滚动条**。
- 相关未展开：匹配结果 + 日志占满；展开后主表仍至少约 6 行可视。
- Win / Linux 同规则。

补丁说明（2026-10-15）：用户反馈外层滚动仍在 → 明确压缩相关进程默认高度。

验收：任意常见分辨率下整窗右侧/底部**无**页面级滚动条；三区数据多时仅区内出现滚动条。
